# Maldiven resources

Original procedural 3D resources created for this project. Geometry and materials have no third-party asset dependencies. All eight runtime GLBs and their Godot import settings are in models/.

Regenerate using Blender: `blender --background --factory-startup --python tools/generate_assets.py`.

See docs/resources.md for dimensions, polygon counts, collision conventions, preview limitations and validation. Preview images and the editable Blender scene are delivered separately; previews/.gdignore keeps them out of the game import pipeline. The project owner can select a distribution license for the original assets.
