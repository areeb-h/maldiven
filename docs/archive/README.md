# Archive

These are the earlier, detailed planning docs for Drift Station (and the island prototype before it): the old plan and roadmap, blueprint, research notes, game-design spec, draft specs, milestone reports and evidence, Android build reports, and ADRs 0002, 0003 and 0006–0019.

They are kept for reference and as an idea bank. They are **not** the active plan: see [design.md](../design.md) and [roadmap.md](../roadmap.md).

Links inside these docs may be stale; files were moved here on 2026-11-15.
