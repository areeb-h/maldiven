        Troubleshooting

        Phones can't find the station?

        Firewall

        The computer must accept incoming UDP on ports 24600 (game) and 24601 (Nearby stations).

          Same network

          Phones and this computer must be on the same Wi-Fi. Guest networks usually keep devices apart: use the main network. Mobile data, VPNs and private relays on the phone also hide the station.

          Router "client isolation"

          Some routers (offices, dorms, hotels, mesh systems) block devices from talking to each other. Look for AP isolation, client isolation or wireless isolation in the router settings and turn it off, or plug the computer into the router with a cable.

          Join by IP

          If the station doesn't show up under Nearby stations, tap Join by IP on the phone and type the address. Joining by IP still needs the firewall and network fixes above.

          Friends elsewhere

          Over the internet you need a UDP tunnel or port forward to UDP 24600 on this computer. Start the server with --public-address to show that address here. Nearby stations only works on the local network.

          Stopping

          Press Ctrl+C in the server's terminal window, or use Stop server here. Phones are told the station is closing and return to their home screen.
